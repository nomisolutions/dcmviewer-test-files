# DCMViewer MacOS
This repo stores dcm files with different compression algorithms for testing purposes.

Files in the supported folder are examples of what the app can open;
Files in the unsupported folder are examples of what the app can not open yet;

# License

The files were taken from the [pydicom](https://github.com/pydicom/pydicom/tree/main/src/pydicom/data/test_files) for testing purposes.
